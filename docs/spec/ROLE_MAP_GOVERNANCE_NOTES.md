# Role Map Governance Notes

Track: Internal Workflow Packaging

This artifact is optional. It exists only if Contracts & Governance is asked to
normalize the final package after C-Suite Command review.

## Purpose

- Normalize approval language
- Tighten handoff wording
- Clarify where founder sign-off is required
- Preserve the existing workflow without changing ownership

## Allowed normalization actions

- Standardize terms such as `founder review`, `handoff`, `owner`, and
  `artifact`
- Clarify which steps are mandatory versus optional
- Tighten statements that could be misread as delegated authority
- Make founder approval boundaries easier to scan

## Disallowed changes

- No reassignment of GPT ownership
- No addition of new workflow stages
- No introduction of new architecture or tooling
- No conversion of optional governance work into a mandatory gate
- No change to `OpsToys` browser-tool naming
- No change to `Custos` naming within Scientia references

## Normalization notes for v1

- Keep all ownership language singular and explicit.
- Keep the founder named as final reviewer, not an observer.
- Keep optional governance language clearly marked as optional.
- Keep the workflow readable by someone who did not participate in prior ATLAS
  chats or screenshot reviews.
