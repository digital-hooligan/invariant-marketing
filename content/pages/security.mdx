Public trust starts with clear separation.

Scientia.io is the public platform surface for trust review, documentation, and qualified entry.
It is not the protected application itself, and this site does not expose operator, admin, founder, or workflow functionality.

## Boundary posture

The public web experience is intentionally separate from protected surfaces.
That means:

- no public exposure of app or operator workflows
- no coupling to private platform internals
- no public access to workspace data
- no implication that internal administrative functions are available here

## Trust review

This public surface is designed to help evaluators understand:

- what Scientia is
- what Scientia.io provides publicly
- how decisions are framed around evidence, context, and accountability
- how qualified access begins without weakening boundary discipline

## Evidence and auditability framing

Scientia uses evidence-first language because important decisions need durable reasoning.
The public site mirrors that posture by making claims conservatively:

- explicit system language
- explicit platform language
- explicit separation between public and protected surfaces
- explicit request-access paths for the next step

## Approved entry points

Use the public site to:

- review security and governance posture
- learn how the system works
- request access or schedule a strategy call

Protected login access is provisioned privately after qualification.
