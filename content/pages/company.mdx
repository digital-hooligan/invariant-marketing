The people behind the system.

Digital Hooligan LLC is the creator and owner of the Scientia system and the Scientia.io platform.
The work is developed and published through the studio identity Invariant.

## Digital Hooligan LLC

Digital Hooligan LLC is the legal company behind the Scientia work.
The company:

- created the Scientia system
- owns the intellectual property for the system
- operates the Scientia.io platform

Digital Hooligan LLC builds systems that improve how organizations structure signals, context, and decisions.

## Invariant - The Studio

Invariant is the studio identity through which the Scientia work is developed and published.
The studio focuses on:

- research and development
- system design
- operational experimentation

Invariant provides the creative and technical environment in which the Scientia system evolves.

## The Scientia System

Scientia is a decision-centric operating model.
The system defines how organizations structure:

- signals
- contextual understanding
- decisions
- execution workflows

Scientia is conceptual. It defines the model organizations can adopt.

## The Scientia.io Platform

Scientia.io is the platform that implements the Scientia system.
The platform provides the operational environment that enables organizations to run the model in practice.
It connects signals, context, decisions, and execution into a structured workflow.

## Direction

The goal of the work is simple:
help organizations build systems where decisions remain understandable, traceable, and accountable over time.

Scientia defines the model.
Scientia.io provides the platform where the model can run.
